(If the ai hop fails, the route degrades gracefully and still returns a reply fragment — never a 500.) 4. {# The HTMX-powered form. The attributes below are what make this a live chat with zero custom JavaScript: - hx-post="/chat" : submit issues an AJAX POST to /chat (not a full navigation), sending the `message` field. - hx-target="#chat-log": the server's HTML response is aimed at this element. - hx-swap="beforeend" : APPEND the response inside #chat-log (as its last child) rather than replacing it — so each new exchange stacks under the previous ones, building a transcript. (Contrast "innerHTML", which would wipe the log each time.) - hx-on::after-request="this.reset()" : after the request completes, clear the input so it's ready for the next message. Because hx-swap appends a fragment, the /chat route returns ONLY the two message bubbles (_chat_reply.html), never a whole base.html page. #}
